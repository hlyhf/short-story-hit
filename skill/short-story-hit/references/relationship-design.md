# 关系设计 · Relationship Design

关系是短篇的发动机。事件再大，如果人物之间"没关系"，读者就不在乎。这一章解决"怎么让人物关系产生戏剧张力"。

## 一、为什么关系是发动机

读者追故事，追的是"人在关系里的反应"。爆款短篇几乎都建立在一组**强错位关系**上：越亲密的关系（夫妻 / 兄妹 / 师徒），错位越狠（仇人 / 替身 / 骗局），越好看。

> 关系即钩子：每一次关系揭露，都是一个新的剧情钩子。

## 二、关系三定律

1. **强关系 + 强错位 = 张力**
   关系越亲密，错位越狠，戏剧张力越大。陌路人反目远不如"最爱的人是最深的仇"。

2. **一层关系藏一层**
   表面关系下埋真实关系，揭一层加一层冲突。例：夫妻（表面）→ 替身（一层）→ 仇人之女（真相）。

3. **关系即钩子**
   不要把关系一次性说透。用"渐进揭露"让关系本身成为持续钩子：读者每发现一层，就多一个继续读的理由。

## 三、6 大高张力关系模型（选 1 打底）

| 模型 | 关系内核 | 爆点 |
|------|----------|------|
| **替身** | 你爱的是我这张脸，不是我 | 真身归来，假身崩塌 |
| **复仇** | 最亲密的人是最深的仇 | 身份揭露，两难抉择 |
| **错认** | 认错了人，付出了一切 | 真相碎裂，追悔莫及 |
| **阶层差** | 云泥之别的爱 | 门第反杀 / 跌落 |
| **养恩血仇** | 养育之恩 vs 灭门之恨 | 两难抉择，撕裂 |
| **契约 / 交易** | 先婚后爱、卖身救亲 | 假戏真做，情动 |

**选型逻辑**：
- 爽文：契约 / 阶层差（逆袭打脸）
- 虐文：替身 / 错认（爱而不得）
- 悬疑：复仇 / 养恩血仇（身份谜团）

## 四、关系递进表（让关系"长"出来）

填表时，每一阶段标一个**钩子动作**——制造"读者必须往下读"的钩子。

| 阶段 | 关系状态 | 读者感受 | 钩子动作（必填） |
|------|----------|----------|------------------|
| **开局** | 表面关系（甜蜜 / 和睦 / 依赖） | 安心 | 埋一个"不对劲"的细节 |
| **转折** | 第一次错位暴露 | 疑惑 | 让角色开始怀疑 |
| **中局** | 真实关系半揭 | 震惊 | 制造两难选择 |
| **高潮** | 关系彻底翻转 | 爽 / 虐爆点 | 角色做决断 |
| **收尾** | 新关系 或 关系崩坏 | 余震 | 留一个关系悬念 |

**示例（替身模型）**：
- 开局：他宠她如命 → 钩子：他总在深夜看一张旧照片
- 转折：她发现自己像照片里的亡人 → 钩子：他喊错名字
- 中局：真身归来 → 钩子：他选谁？
- 高潮：他原来爱的是替身里的"活气" → 爆点
- 收尾：她离开，他追 → 悬念：追到与否

## 五、关系张力自检

- ✅ 主角之间是否存在"强关系 + 强错位"？
- ✅ 关系是否分层揭露（至少 2 层）？
- ✅ 每个关系节点是否同时是钩子（推动阅读）？
- ❌ 如果关系是"普通朋友吵架"，张力不够 → 升级为更亲密 / 更错位的关系。

## 六、与钩子、反转的配合

- 钩子常由"关系错位"直接产生（见 `hook-design.md`）。
- 反转常由"关系真相揭露"产生（见 `emotion-curve.md`）。
- 三者闭环：关系错位 → 开篇钩子 → 关系揭露 → 反转 → 余震。
