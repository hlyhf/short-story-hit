# AI 扩写提示词模板 · AI Expand Prompt

你搭好骨架（靶心 + 钩子 + 关系表 + 反转）后，用这个模板让 AI 扩写成 800–2000 字成品。模板把本技能的方法论"喂"给 AI，确保扩写不走样。

## 一、标准扩写 Prompt（复制填空）

```
你是一位短篇爆款写作专家。请根据以下骨架，扩写成一篇 1500 字左右的短篇故事。

【情绪靶心】<爽/虐/爽虐/悬>：<一句话说明读者爽点>
【开篇钩子】使用"<5公式之一>"：<你的前三句钩子>
【人物关系】模型：<替身/复仇/错认/阶层差/养恩血仇/契约>；递进：<开局→转折→中局→高潮→收尾 各一句>
【反转设计】<认知/情境/身份反转，写在第几段>
【收尾】<爆点落幕 / 悬念断点>

【写作铁律，必须严格遵守】
1. 前三句必须出现冲突/异常/悬念，禁止环境铺垫和背景介绍。
2. 每 1/3 篇幅至少一个反转或新钩子，中段不能塌。
3. 人物关系分层揭露（至少 2 层），关系即钩子。
4. 结尾要么情绪炸裂后骤停，要么留一个未解悬念，禁止"从此幸福"式敷衍。
5. 禁止说教、禁止注水心理独白（单段不超 3 句）、禁止价值观硬伤。
6. 全程口语化、有画面感，每句话要么是钩子要么是推进。

请直接输出故事正文，不要输出分析。
```

## 二、变量说明
- `<情绪靶心>`：从 `case-matrix.md` 选。
- `<5公式>`：身份逆转 / 绝境开局 / 隐藏身份 / 倒计时 / 惊天揭露（见 `hook-design.md`）。
- `<关系模型>`：6 选 1（见 `relationship-design.md`）。

## 三、扩写后必做
1. 跑 `structure_check.py` 体检（字数 / 钩子 / 反转 / 关系 / 评分）。
2. 对照 `hit-checklist.md` 人工终检。
3. 若评分 < 8，回到骨架层修关系或反转，再扩写，不要硬改成品。

## 四、进阶：分镜/剧本移交
如果扩写后想改成剧本 / 分镜，把"靶心 + 关系表 + 反转点"交给 `drama-studio` 技能，它会按剧创制式（字数 / 场景 / S 级评分）重写。移交时附上本技能的 `relationship-design.md` 关系表，衔接最顺。
