# 爆款自检清单与红线 · Hit Checklist

写完故事，用这份清单做最后一道关。全部通过，才算"爆款胚子"。

## 一、爆款自检清单（✓ 全过才放行）

- [ ] **开篇钩子**：前三句出现冲突 / 异常 / 悬念，无环境铺垫、无背景介绍
- [ ] **情绪靶心**：用一句话能说清读者会"一爽 / 一虐 / 一好奇"
- [ ] **关系张力**：主角间存在"强关系 + 强错位"，且分层揭露（≥2 层）
- [ ] **反转密度**：每 1/3 篇幅至少一个反转或新钩子，中段不塌
- [ ] **钩子兑现**：开篇抛的每个悬念，中后段都有落地或翻转
- [ ] **结尾余震**：爆点落幕 或 悬念断点，无"从此幸福"敷衍
- [ ] **篇幅控制**：短篇 800–2000 字为佳，无废笔（每句要么钩子要么推进）
- [ ] **平台适配**：开头 / 节奏 / 结尾匹配目标平台（见 `platform-adapt.md`）

## 二、红线（触碰即废，禁止）

1. **平淡开头**：前三句还在写景 / 介绍背景 → 读者已划走
2. **无关系张力**：人物是"普通朋友吵架"级别 → 读者不在乎
3. **无反转**：平铺直叙到结尾 → 没有记忆点
4. **说教尾巴**：结尾硬塞道理 / 价值观宣讲 → 出戏
5. **拖沓注水**：为凑字数加无关描写 / 心理独白 → 完读率暴跌
6. **钩子骗人**：开头抛悬念全文不揭 → 被骂"标题党"
7. **价值硬伤**：鼓吹违法 / 极端复仇无代价 / 物化歧视 → 平台下架

## 三、简易评分（10 分制）

| 维度 | 分值 | 评分标准 |
|------|------|----------|
| 开篇钩子 | 2 | 强 2 / 中 1 / 弱 0 |
| 关系张力 | 2 | 强错位 2 / 一般 1 / 无 0 |
| 反转质量 | 2 | 自然且炸 2 / 生硬 1 / 无 0 |
| 结尾余震 | 2 | 有钩子 / 爆点 2 / 平淡 1 / 敷衍 0 |
| 节奏紧凑 | 2 | 无废笔 2 / 偶有拖沓 1 / 注水 0 |

**≥8 分**：爆款胚子，可直接发。**6–7 分**：修关系或反转后发。**<6 分**：重搭骨架。

## 四、机器辅助体检

除人工对照本清单外，可跑脚本做客观体检：
```bash
python3 ../scripts/structure_check.py 你的故事.md
```
脚本会核对字数、开篇钩子关键词、反转计数、关系模型命中，并给改进建议（详见脚本说明）。
