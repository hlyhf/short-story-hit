# 角色速建卡 · Character Builder

关系是发动机，但发动机得装在人身上。这一章用"卡片"在三分钟内立起可用的主角 / 反派 / 工具人，避免人物扁平。

## 一、主角速建卡（必填）

| 维度 | 填什么 | 为什么 |
|------|--------|--------|
| **表层身份** | 职业 / 阶层 / 状态 | 读者第一眼认知 |
| **隐藏伤口** | 一个没愈合的痛（驱动全篇） | 行为动机，读者共情源 |
| **致命弱点** | 一个会害他栽跟头的特质 | 制造困境与成长弧 |
| **想要 vs 需要** | 他以为要的 / 真正需要的 | 结尾反转的落点 |
| **关系错位** | 与谁错位（见 relationship-design） | 张力来源 |

**模板**：
> 主角___（身份），表面___，其实藏着___（伤口）。他最大的弱点是___。他以为自己要___，但其实需要___。他和___的关系是错位的——___。

## 二、反派速建卡

| 维度 | 填什么 |
|------|--------|
| **自认的正义** | 反派必须觉得自己对（偏执 / 被辜负 / 保护欲） |
| **与主角镜像** | 反派是主角的"暗面版本"（同一伤口的不同解法） |
| **破绽** | 一个可被主角击中的软肋 |

**铁律**：没有"为坏而坏"的反派。读者恨得越深，越说明你写活了他。

## 三、工具人速建卡（配角）

工具人不是人，是**功能**：
- **递钩子者**：抛出关键信息 / 制造误会的角色
- **推反转者**：在转折点递刀 / 揭真相的角色
- **试金石**：用他的反应衬托主角变化

**自检**：每个配角是否至少承担一种功能？纯背景板一律删。

## 四、速建示例（爽+错认主角）

> 主角**顾言**，表面是入赘废物，其实藏着**被家族流放的继承人之痛**。他的弱点是**心软**，总给欺辱他的人留余地。他以为自己要**报复岳家**，但其实需要**找回被否定的自我**。他和岳家的错位是——**他们骂的废物，正是他们高攀不起的人**。

## 五、与双引擎衔接
- 主角"隐藏伤口"往往就是关系错位的伏笔。
- 反派"镜像"让反转更有力（主角战胜反派=战胜自己的暗面）。
- 工具人卡对应 `hook-design.md` 的钩子动作与 `emotion-curve.md` 的反转节点。
