# 发布三件套 · Release Kit

故事写完 ≠ 能爆。平台只给你三样东西露出：**封面标题、开头三句、结尾一句**。这三件套必须指向同一个情绪靶心，任何一个掉链子，完读率就漏。这一章把它们打包，并给你发布与回收数据的闭环。

## 一、三件套一致性原则

> 标题承诺的情绪 = 开头三句给的情绪 = 结尾一句兑现的情绪。

- 标题写"虐"，开头却是搞笑日常 → 读者被骗走，跳出率爆炸。
- 开头给"爽"，结尾却是大段说教 → 情绪不兑现，没有转发。
- 自检：把三件套单独抽出来读一遍，是不是同一个故事、同一种心跳？

## 二、第 1 件：封面标题（决定点不点开）

标题公式（详见 hook-arsenal.md 第二节，这里是选用逻辑）：

| 平台 | 首选公式 | 字数 | 要点 |
|------|----------|------|------|
| 小红书 | 悬念式 / 情绪式 | 18 字内 | 留白带emoji，别剧透反转 |
| 知乎 | 数字式 / 对话式 | 25 字内 | 制造"我也想问"的代入 |
| 公众号 | 反差式 / 身份式 | 22 字内 | 前 13 字必须出钩子 |
| 番茄 | 身份式 / 悬念式 | 15 字内 | 一眼看懂人设反差 |

**标题铁律**：含情绪词（爽/虐/疯/破防）+ 具体反差 + 省略号/问号留白。写完自问：我会想点进去吗？

## 三、第 2 件：黄金前 3 句（决定看不看完）

- 前 3 句 = 前 3 秒。平台完读率数据里，70% 以上的流失发生在前 3 句。
- 套公式：`[反常动作] + [身份/处境反差] + [未解悬念]`（见 hook-design.md）。
- 第一句尤其要命：必须是"动作"或"揭露"，不能是"介绍"。
  - ❌「林晚是个普通女孩」❌「江南的春天很美」
  - ✅「林晚把订婚宴的酒倒进对方杯里时，没人知道那里面沉着她亲哥的骨灰」
- 机检：`structure_check.py` 的「第1-3句逐句钩子」全命中才算过。

## 四、第 3 件：末句金句（决定转不转发）

- 结尾 ≤30 字，二选一：
  - **爆点骤停**：打脸/揭露后立刻收，不给缓冲。
  - **悬念留白**：留一个未解的东西，引人评论 / 期待续集。
- 金句按情绪选（见 hook-arsenal.md 第三节 20 条金句库），核心：金句是"情绪浓缩"，不是"道理总结"。
  - ❌「她明白了人要向前看」
  - ✅「原来被爱的前提，是我长得像另一个人」

## 五、平台发布 Checklist

### 小红书
- [ ] 18 字内标题 + 留白 emoji（😭/😱/🆘）
- [ ] 正文 500–800 字（短篇可分 2–3 篇发，文末钩"下集"）
- [ ] 每 3–4 行空一行（手机屏阅读）
- [ ] 标签：#短篇小说 #推文 #虐文 #反转 + 题材词（#民俗怪谈）
- [ ] 首图：大字报封面（标题大字 + 冲突画面）

### 知乎
- [ ] 25 字内问题式标题
- [ ] 正文 1500–3000 字（知乎吃长，反转放最后 1/5）
- [ ] 开头别抒情，直接进冲突
- [ ] 结尾留一个"细思极恐"的钩子引讨论（评论=流量）

### 公众号
- [ ] 22 字内，前 13 字出钩子
- [ ] 正文 1200–2000 字
- [ ] 段落 ≤4 行，多用短句
- [ ] 结尾金句单独成段（方便截图转发）

### 番茄（故事/短文）
- [ ] 15 字内人设反差标题
- [ ] 每章 1000–1500 字，章尾必须留钩
- [ ] 前 3 章决定生死，钩子密度拉满

## 六、发布后：数据回收闭环（让 skill 越用越准）

发布后 48–72 小时，回收三个数，回填到你的选题笔记：

| 指标 | 怎么判断 | 归因动作 |
|------|----------|----------|
| **完读率** | 平台后台 | 低 → 查开头三句 / 中段塌陷（跑 structure_check） |
| **跳出位置** | 读者在哪句流失最多 | 集中跳出点 = 必改句 |
| **评论高频词** | 读者在讨论什么 | 情绪没打中？反转没看明白？ |

**回填规则**：哪种情绪×关系跑得好，就优先在 case-matrix.md 对应格子再产；哪种开头完读率高，就把它的句式抽象进 hook-arsenal.md。爆款不是写出来的，是回收数据喂出来的。

## 七、发布前最终检查（30 秒）

- [ ] 三件套（标题/开头/结尾）情绪一致？
- [ ] 前三句过钩子公式？
- [ ] 结尾 ≤30 字且有余震？
- [ ] structure_check.py ≥8 分？
- [ ] 过了 death-causes.md 十大死因速查？
