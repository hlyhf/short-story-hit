# 反套路与创新 · Anti-cliché & Innovation

爆款会被抄烂。这一章帮你避开烂俗、踩中趋势，让故事"熟里带新"。

## 一、过时套路清单（能不用就不用，用必翻新）
| 套路 | 为什么腻 | 翻新方向 |
|------|----------|----------|
| 霸总强制爱 | 2018 款，读者免疫 | 改"女霸总"或"反被拿捏的霸总" |
| 车祸失忆 | 烂尾三件套之一 | 改"记忆被篡改"而非丢失 |
| 带球跑 | 用过亿次 | 改"带秘密跑"而非带孩子 |
| 灰姑娘 | 阶层逆袭审美疲劳 | 改"双向救赎"或"阶层反杀" |
| 复仇傻白甜 | 无脑爽腻 | 改"高智商复仇 + 自我怀疑" |

## 二、当前趋势（2025–2026 有效）
- **女性觉醒**：女主不再等救，主动破局（《抓娃娃》式反杀）。
- **轻克苏鲁 / 民俗怪谈**：日常里的细思极恐（见 `case-matrix.md` 悬类）。
- **追妻火葬场变体**：从"他后悔"升级为"她根本不想回头"。
- **职业爽文**：医生 / 律师 / 厨师用专业打脸（专业感 = 新意）。
- **代际和解 / 养老焦虑**：现实情绪靶心，共鸣强。

## 三、创新三法
1. **反转套路**：先给读者预期套路，再在第三幕掀桌。例：以为是霸总文，结果是女主设局反杀。
2. **视角切换**：用反派 / 配角 / 物品视角讲同一件事，陌生感即新意。
3. **留白代替解答**：不把所有谜说透，读者参与补全，传播力更强（适合小红书/知乎）。

## 四、创新自检
- 这个故事的"爽点 / 虐点"三年前能发吗？能 → 太旧，翻新。
- 主角有没有"主动选择"？纯被动挨打 → 旧。
- 结尾有没有超出读者预期半步（不是离谱，是巧）？没有 → 平。

## 五、红线提醒
创新不等于踩线。价值观硬伤（鼓吹违法 / 极端复仇无代价 / 物化歧视）无论多新都会被下架，见 `hit-checklist.md` 红线。
